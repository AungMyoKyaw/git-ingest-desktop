# Git-Ingest

Git-Ingest is a local-first desktop utility that turns a repository into focused, inspectable context for LLM and coding-agent workflows.

> v1.0.0 is a complete rewrite using Tauri, Rust and Svelte. Repository content is processed locally; Git-Ingest has no account, telemetry, analytics, or model API integration.

## Features

- Open or drop a local repository and inspect files before export.
- Git branch/status and per-file diff awareness.
- Deterministic relevance ranking with explanations.
- Include/exclude/pin overrides and token budgets; pinned files are never silently trimmed by the budget.
- Source/docs/tests/changed/skipped filters, search, preview and dependency hints.
- General, ChatGPT, Claude, Codex and Gemini workflow presets (defaults, not provider limits).
- Reusable profiles, recent projects, optional live refresh, keyboard shortcuts.
- Markdown or plain-text context; copy, save, open and reveal exports.
- Least-privilege Tauri boundary: renderer code has no generic filesystem or shell permission.

## Development

```bash
bun install --frozen-lockfile
bun run dev:desktop
```

The browser-only frontend can be started with `bun run dev`, but native repository operations require Tauri.

## Configuration

No environment variables or remote credentials are required for normal use. Settings, recent projects and saved rule profiles are persisted in the Tauri app config directory. The selected repository remains the trust boundary for all read operations.

## Commands

```bash
bun run dev            # Vite frontend
bun run dev:desktop    # Tauri development app
bun run format         # Prettier + rustfmt
bun run format:check   # formatting gate
bun run lint           # ESLint + Clippy -D warnings
bun run typecheck      # svelte-check

bun run coverage       # frontend + Rust coverage
bun run build          # production frontend
bun run build:desktop  # Tauri package build
bun run audit          # Bun + Cargo vulnerability audit
bun run verify         # aggregate quality gates
bun run clean          # generated output cleanup
```

## Testing and coverage

The release target is 100% statements, branches, functions and lines for project-owned executable code. Frontend coverage is enforced by Vitest/V8. Rust coverage is collected with `cargo-llvm-cov`; the release workflow also checks branch coverage instead of treating line coverage as a substitute.

Required tests may not be skipped, ignored, focused-only or marked todo.

## Building and packaging

```bash
bun install --frozen-lockfile
bun run build:desktop
```

Tauri writes platform bundles under the Cargo target directory. Signing and notarization are release-environment concerns; the project does not claim an unsigned artifact is notarized.

## Usage

1. Open **Project** and choose or drop a repository.
2. Use **Context** to search, inspect, include/exclude or pin files and review Git changes.
3. Use **Rules** to set path patterns, token/file budgets, output format or a saved profile.
4. Use **Output** (or `⌘/Ctrl+G`) to generate, copy or save context.

Shortcuts: `⌘/Ctrl+O` choose project, `⌘/Ctrl+F` search context, `⌘/Ctrl+,` rules, `⌘/Ctrl+G` generate.

## Troubleshooting

- **A file is skipped:** inspect its skip reason in Context. Binary, non-UTF-8, oversized and generated/dependency content is rejected before ranking.
- **Token budget trims files:** pin a required file; pins survive budget trimming but cannot bypass safety rules.
- **No Git metadata:** Git-Ingest still works on non-Git folders; Git status/diff is simply unavailable.
- **Desktop build fails:** verify Tauri's OS dependencies and the exact Bun/Rust versions used by CI.

## Security

Git-Ingest does not expose a generic filesystem API or shell plugin to the renderer. Git commands use a fixed executable with fixed argument structure, and user-relative paths are canonicalized and confined to the selected root. See [SECURITY.md](SECURITY.md).
